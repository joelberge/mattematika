# Mattematika

Gratis mattehefter i pikselstil for barn 6–10 år. Foreldre velger spill (Monsterkamp eller Dyreredning) og nivå,
ser kartet over verdenen, og laster ned et ferdig hefte (PDF) som skrives ut.

- `index.html` – nettsiden
- `hefte/` – heftene (`monsterkamp.html`, `dyreredning.html`), oppgavesettene (`sett.js`) og tilpasningen (`helt.js`)
- `pdf/` – ferdige hefter med standardnavn, nivå 1–3
- `kart/` – kartene som vises før nedlasting

Statisk side uten byggesteg. Fungerer på GitHub Pages, Netlify eller Cloudflare Pages.
Eget domene på GitHub Pages: legg domenet i en fil som heter `CNAME` og pek DNS mot GitHub.
